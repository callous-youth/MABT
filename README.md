# MABT

Official code repository for the NeurIPS 2026 Spotlight paper:

> **Anchoring Adversarial Trajectories to Data Manifolds: A Bilevel Transfer Optimization Framework**
> Yaohua Liu, Yifan Guo, and Jiaxin Gao

**Manifold Anchored Bilevel Transfer (MABT)** improves adversarial transferability by anchoring optimization trajectories to data manifolds and learning a transferable initialization through distributional bilevel optimization.
